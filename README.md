# Animated Navigation Bar

Projeto desenvolvido com HTML e CSS que apresenta uma barra de navegação animada. O menu utiliza radio buttons para controlar o estado ativo dos itens e um indicador deslizante que acompanha a seleção do usuário.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Font Awesome

## ✨ Funcionalidades

- Menu de navegação animado
- Indicador deslizante (slider)
- Ícones personalizados
- Seleção de abas sem JavaScript
- Interface moderna
- Efeitos visuais com CSS puro

## 🎯 Como Executar

1. Clone ou baixe o projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em qualquer navegador.

- HTML semântico

## 💡 Objetivo

Praticar a criação de componentes de navegação modernos utilizando apenas HTML e CSS, explorando técnicas de animação e interação sem JavaScript.
